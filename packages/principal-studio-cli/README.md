# @principal-ai/principal-studio-cli

CLI for **Subsystem Models**, **Subsystems Studio**, trails, and agent sessions.

## Install

```bash
npm install -g @principal-ai/principal-studio-cli
```

Or via npx:

```bash
npx @principal-ai/principal-studio-cli --help
```

Bin name: `principal-ai`.

## Commands

| Command | Purpose |
|---|---|
| `subsystem-model` | Create / open / list / get subsystem models |
| `open-studio` | Launch or focus Subsystems Studio |
| `trail` | File City trails |
| `tour` | Introduction tours |
| `topic` | Topics |
| `inbox` | Inbox |
| `starred-collections` | Starred GitHub collections |
| `repo` | Repo helpers |
| `opencode` | OpenCode session helpers |
| `agent-sessions` / `agent-session` | Agent session views |

Legacy observability-canvas / `.principal-views` / OTEL validate commands were removed from this package.
